# monportefolio

Portfolio statique de Léo Martin.

## Déploiement

Le site est déployé automatiquement sur GitHub Pages à chaque `push` sur `main`.

1. Ouvrir `Settings > Pages` dans le dépôt GitHub.
2. Dans `Build and deployment`, choisir `GitHub Actions` comme source.
3. Attendre la fin du workflow `Deploy to GitHub Pages` dans l’onglet `Actions`.

Le site sera ensuite disponible à l’adresse :
`https://codeappli09-lgtm.github.io/monportefolio/`
